# 인게임 메뉴 UI 리소스 확인 — 2026-11-01

## 참고 화면과 범위

사용자가 제공한 삼국지8 REMAKE 인게임 정보·편집 화면을 기준으로, 밝은 종이 배경, 갈색 금장 버튼, 노란 선택 탭, 붉은 팔각형 뒤로 버튼을 확인했다. `image(20261101-042938).png`는 우측 상단 환경설정 아이콘 아래의 런처 정렬 기준이며, `image(20261101-043812).png`는 하단 중앙에 쌓이는 종이 띠 알림의 참고다. 아래 내용은 첨부 원본과 픽셀 분석에 근거한 리소스 기록이다. 실제 게임에서의 실행 결과는 별도 검증 항목에서 구분한다.

part01~05에는 합계 G1T 45개, PNG 99개, 이름이 있는 sprite UV 레코드 2,457개가 있다. 한국어·중국어 글자와 글리프가 주를 이루며, 버튼 바탕과 종이 배경 선택에는 Sam8RE 묶음을 사용했다. 포함된 추출·디코드 스크립트는 실행하지 않았다.

같은 파일명이라도 크기가 다를 수 있다. 예를 들어 ZIP의 `5889d015_fca8b1c7de_000.png`는 4096×2048이고, 앞서 제공된 개별 첨부에서 가져온 현재 `compact_controls.png`는 2048×1024다. 아래 UV는 각 행에 명시한 실제 이미지 크기에만 적용한다.

## 선택 리소스 및 픽셀 영역

모든 좌표는 `[left, top, right, bottom)`이며, 원본 PNG의 alpha를 유지한다. 투명 영역의 검정 RGB를 색상 키로 제거하지 않는다. 원본은 자르거나 다시 인코딩하지 않고 렌더링 시 UV로 선택한다.

### 종이 배경과 산수

Sam8RE 원본 `e9ed623d_6cb25e2cc1_011.png` — **2048×2048**.

| 용도 | 좌표 | 확인 사항 |
|---|---|---|
| 종이 배경 | `{0, 0, 1280, 720}` | alpha 249~255, 평균 RGB 약 218/206/191. |

## 환경설정 아이콘 아래 고정 위치

`image(20261101-042938).png`는 2048×1187이고, 상단 Windows 제목 표시줄 36px를 제외한 게임 클라이언트는 2048×1151이다. 1920×1080 기준 약 1.066배다. 위 환경설정 sprite를 50~60px로 비교하면 59px 크기, 캡처 좌상단 `(1976, 68)`에서 가장 잘 맞는다. 이는 클라이언트 기준 약 `(1976, 32)`이다.

화면이 일반 16:9 기준으로 구성된 경우 다음 기준으로 같은 세로축을 재현할 수 있다.

```text
s = min(client_width / 1920, client_height / 1080)
launcher_center_x = client_width - 40 * s
launcher_top = 106 * s
launcher_edge = 56 * s
```

클릭 영역을 더 크게 만들 때도 중심 x를 유지한다. 편집창 좌표나 이전 최소화 위치, Windows DPI와 분리하여 게임 클라이언트 크기로 정렬해야 한다. 이 수치는 제공된 캡처의 HUD 위치를 측정한 값이며, 게임 내부에서 환경설정 컨트롤 좌표를 직접 읽은 결과는 아니다. 다른 화면 비율·게임 UI 배율은 별도 확인한다.
